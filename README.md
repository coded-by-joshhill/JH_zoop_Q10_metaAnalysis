# Zoop_Q10_metaAnalysis

A repository for the Q10 meta-analysis section of 'Meta-analyses show pervasive climate change impacts on zooplankton'.

The folder structure and contents are as follows:

### Data

Here I save data files such as RDS and CSV.

- CSV files are the original, raw data files of empirical Q10 observations and model-specifc Q10 values

- RDS files are the cleaned or summarised data frames that are used in subsequent scripts.

### R

This folder contains all .R scripts that are used for either data cleaning or data analysis.

### Output

This folder contains any output used in the manuscript or supplementary materials.
